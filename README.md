## Setup
To build and run the project, follow the simple steps below:

**Virtual Environment**
`cd` into the `src` directory and run the following command:

```shell
python -m venv .venv 
```

**Activate Virtual Enviroment**
To activate the newly created virtual environment and set it as the current environment, run:

```shell
source .venv/bin/activate
```

**Install Packages**
Install the external libraries used by this project:

```shell
pip install -r requirements.txt
```
